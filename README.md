# Daybook

## Run

```
python app.py
```

Opens http://localhost:8765. Data is stored in `tasks.json` next to `app.py`.

## Windows

```
daybook.cmd            start (restarts if already running) and open in browser
daybook.cmd install    start automatically at login
daybook.cmd uninstall  remove autostart
daybook.cmd update     download the latest app.py, then restart
```
